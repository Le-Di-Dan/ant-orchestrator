# Checklist — Pre-Coding

Trước khi sửa code, Claude phải tự kiểm:

- [ ] Tôi đã hiểu mục tiêu task chưa?
- [ ] Phạm vi nhỏ nhất cần sửa là gì?
- [ ] File nào liên quan trực tiếp?
- [ ] Có cần đọc foundation/technical docs không, hay chỉ cần skill cụ thể?
- [ ] Có cần sub-agent không? Nếu không thật sự cần, không dùng.
- [ ] Có rủi ro kiến trúc cần hỏi PO trước không?

Plan trước khi code tối đa 5 bước.
